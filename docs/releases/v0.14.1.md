# CanvaStage v0.14.1

This release adds an optional workaround for [#47](https://github.com/mj00009/CanvaStage/issues/47), where Canva's PowerPoint export contains uppercase text that differs from the editor and Presenter.

## Use the workaround

Open **Settings & Diagnostics → Monitor text capitalization**, enable **Match slide capitalization**, then **Re-download** the applied deck. **Apply** and **Start setup** can also process an unchecked deck. The setting is off by default.

CanvaStage uses local Windows OCR on the slide images it already downloads. It changes casing only in long uppercase sections whose words match the image text. Wording, numbers, punctuation, line breaks, existing mixed-case names and isolated acronyms stay as exported. Uncertain or conflicting matches keep the original text. There is no additional PDF export, third-party PDF/OCR library or remote recognition service.

The status reports pages adjusted, candidate pages kept as exported, and pages that could not be checked. Original and matched text are cached separately. Turning the setting off restores the exported text immediately, including current and next cues, while preserving live and blank states. The saved preference applies after restarting the app. Mirror images are unchanged.

## Limits and acceptance

The supplied screenshot/PPTX example passed a private local test, and neutral import/rendering tests pass. Recognition on the affected slide's actual compressed Canva JPEG export still needs operator acceptance. This is a conservative workaround, not a fix to Canva's exporter; #47 remains open for that check.

Windows needs a supported recognition language for the user's profile. Missing support, image limits, recognition failures and timeouts retain the exported text. Processing can lengthen imports, but it runs only on candidate pages and adds no Canva export requests. Short uppercase labels are deliberately left alone. OCR can misread capitalization even when the words agree, so review Monitor against Canva before service use.

## Download

Download `CanvaStage-v0.14.1-win-x64.zip`, extract it into a new folder, and run `CanvaStage.Windows.exe` using the normal Windows operator account. Saved credentials, cached content and preferences carry over. The Windows 11 x64 package remains unsigned, portable and self-contained, with `LICENSE` and `TRADEMARKS.md` beside the executable.

Help and F1 open the [v0.14.1 guide](https://mj00009.github.io/CanvaStage/v0.14.1/). See [capitalization development notes](../development/slide-capitalization.md) for matching rules and test scope.
