# CanvaStage v0.12.1

This patch adds a Help button and F1 shortcut that open the public guide for the installed app version.

## Changes

- Choose Help in the main window, or press F1 while that window has focus. F1 also works in Compact view.
- The website has a Sunday quick start, first-time and advanced setup, troubleshooting, and demo screenshots. Guides for earlier versions stay available.
- Help opens in your default browser and requires internet access. The link contains no presentation, account, or diagnostic data. If the browser cannot be opened, CanvaStage shows the address so you can copy it.
- Opening Help does not change Presenter following, the output display, or the selected page. Presentation downloads, rendering, and display behavior are unchanged from v0.12.0.

## Download and use

Download `CanvaStage-v0.12.1-win-x64.zip`, extract it into a new folder, and run `CanvaStage.Windows.exe` using the same Windows account as before. Saved connection details, downloaded content, and preferences carry over.

The package remains unsigned, portable, and self-contained for Windows 11 x64. It includes the Apache-2.0 `LICENSE` and `TRADEMARKS.md`. You do not need to install .NET or run the app as administrator.

After installing, confirm v0.12.1 in the title bar, choose Help, then try F1 in Full view and Compact view. Both should open [the v0.12.1 guide](https://mj00009.github.io/CanvaStage/v0.12.1/). Check that output and following continue while the browser is open.
