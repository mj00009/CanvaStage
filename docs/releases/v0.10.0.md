# CanvaStage v0.10.0

This release adds automatic Canva content updates and fixes the three reported GitHub issues. It remains an unsigned, self-contained Windows 11 x64 portable package.

## Changes

- [#19 — Automatic content updates](https://github.com/mj00009/CanvaStage/issues/19): CanvaStage checks the applied presentation for edits every 30 seconds. New content downloads in the background, then replaces the deck while preserving the latest matching Presenter page, manual pause, output mode, appearance, and blank state. Automatic updates are enabled by default and can be disabled under **Presentation**. Canva export preparation and download still take time, so updates are not instantaneous.
- Refresh robustness: import and cache saving run off the UI thread, progress notifications are throttled and coalesced, and text fitting no longer runs for unrelated status updates. Ordered output notifications prevent a deck swap from overwriting a newer Presenter-page selection. Failed refreshes retain the working deck and retry with backoff.
- [#18 — Saved authorization](https://github.com/mj00009/CanvaStage/issues/18): startup loads presentation choices without opening the browser when saved authorization is valid. Expired or rejected access tokens renew automatically, with serialized refresh-token rotation. Revoked authorization still requires explicit reconnection; protected client configuration is retained.
- [#17 — Single-line next cue](https://github.com/mj00009/CanvaStage/issues/17): next-slide cues use the first authored nonempty line and occupy one visual line, with word ellipsis for long paragraphs. PPTX soft line breaks are preserved, and the main slide text remains complete.
- **Re-download** refreshes the applied presentation rather than an unrelated highlighted dropdown entry.
- Expanded Windows verification covers delayed live refresh with page navigation, changed page counts, failed downloads, pause/blank preservation, token renewal, automatic-update opt-out, shutdown cancellation, and screenshots of the new controls and next cue.

## Install or upgrade

1. Close the previous CanvaStage application.
2. Download `CanvaStage-win-x64.zip` from this release and extract the complete ZIP into a new folder.
3. Run `CanvaStage.Windows.exe` using the same Windows account as before. The existing local cache, preferences, and protected Canva setup are reused; do not clear cache or disconnect as part of upgrading.
4. Confirm **Automatically apply Canva content updates** is set as desired under **Presentation**.

The ZIP includes the Apache-2.0 license and trademark notice. No installer, code signing, or automatic application updates have been added. Windows may show an unsigned-app warning.

## Please test

The functional fixes passed 50 unit tests and published Windows synthetic/UI verification before release preparation. These do not replace testing with the church's Canva account and physical displays.

- Restart and confirm the presentation list loads without a browser prompt. Repeat after the access token has expired.
- While presenting, edit the applied Canva deck, navigate pages, switch modes, and blank/restore output during the download. Confirm output remains responsive and resumes showing the current page with the updated content.
- Add or remove a visible page and confirm a temporary page-count mismatch resolves after the refreshed deck arrives.
- Test a failed download or disconnected network: the previous deck should remain usable and refresh should recover after connectivity returns.
- Confirm long next-slide paragraphs occupy only one cue line in the in-app preview, separate Preview, and confidence output.

If the reported refresh freeze persists, include reproduction steps and a sanitized diagnostics ZIP from **Setup & diagnostics**. See the full [Windows acceptance guide](../windows-acceptance.md).
