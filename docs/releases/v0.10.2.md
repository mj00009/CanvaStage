# CanvaStage v0.10.2

This maintenance release fixes automatic content-check scheduling and makes refresh health visible in Live control. It remains an unsigned, self-contained Windows 11 x64 portable package.

## Changes

- [#20 — Automatic content updates](https://github.com/mj00009/CanvaStage/issues/20): the next automatic check is scheduled 30 seconds after the previous check or download finishes. The old fixed timer and separate deadline could skip a tick and stretch checks to about a minute. Checks continue without opening Presentation, do not overlap other Canva actions, and back off after failures up to five minutes.
- A **Content refresh** card in **Live control** shows checking/downloading state, last completed metadata check, last content load, next check or retry time, download progress, and safe failure details. Failed downloads retain the working presentation; turning automatic updates off or losing authorization is also reported.
- Unchanged presentations receive metadata checks only. Changed presentations still download the complete visible deck. Selective image refresh is deliberately deferred.
- Newly downloaded content replaces the working deck without restarting CanvaStage output or Presenter tracking. The matching current page, manual pause, appearance and blank state are preserved. Adding or removing pages can temporarily cause a count mismatch until the updated deck is ready.
- Regression coverage includes monotonic scheduling, bounded retry delays, real Windows timer checks while staying in Live control, no repeated exports for unchanged content, busy/download overlap prevention, retry recovery, opt-out and shutdown, plus refresh-health screenshots.

## Install or upgrade

1. Close CanvaStage.
2. Download `CanvaStage-win-x64.zip` and extract the complete ZIP into a new folder.
3. Run `CanvaStage.Windows.exe` using the same Windows account as before. Existing preferences, cached content, and protected Canva setup are reused. Do not clear cache or disconnect as part of upgrading.

The ZIP includes the Apache-2.0 license and trademark notice. Windows may show an unsigned-app warning. No installer or signing has been added.

## Please test

All 59 unit tests pass locally. The release workflow additionally runs the published Windows app's synthetic verification; real-account and physical-display testing are still needed.

- Leave **Live control** open with an unchanged Canva deck for several minutes. Confirm the last-check time advances about 30 seconds after each check completes and repeated downloads do not occur.
- Edit a slide without opening Presentation. Wait for Canva's modification timestamp and exports to become available, then confirm the refresh card shows progress and the new content appears without restarting output or tracking.
- Navigate Presenter, switch Mirror/Monitor, and blank/restore output during a download. Confirm output remains responsive and retains the current matching page after the swap.
- Disconnect the network during a refresh. Confirm the working deck remains usable, Live control shows an error and retry time, and the error clears after recovery. Turning automatic updates off must stop subsequent checks.
- Check the refresh card at your normal Windows display scaling. Its text should remain legible and wrap within the panel.

Automatic checks still depend on Canva reporting a newer edit timestamp. A successful metadata check does not prove that Canva has published every recent edit. If an edit is missing, use **Check for updates** with automatic updates enabled, or **Re-download**. Export preparation and large downloads can take several minutes. CanvaStage does not force Canva's own Presenter window to reload edits.

Issue #20 remains open for confirmation with this version. If it persists, include the refresh-card state/times, affected mode, button used, and a sanitized diagnostics ZIP from **Setup & diagnostics**. See the full [Windows acceptance guide](../windows-acceptance.md).
