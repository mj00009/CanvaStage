# CanvaStage v0.10.3

This maintenance release addresses two Monitor typography issues. It remains an unsigned, self-contained Windows 11 x64 portable package.

## Changes

- [#22 — Auto text sizing flash](https://github.com/mj00009/CanvaStage/issues/22): both the in-app preview and the separate confidence window fit current text during layout, before its first rendered frame. Slide changes no longer reset visible text to the requested large size before shrinking it. The selected size remains a maximum; longer content still shrinks to fit.
- [#23 — Next cue font mismatch](https://github.com/mj00009/CanvaStage/issues/23): current text and the Next cue share the selected font family and default semibold weight. The Next cue retains its independent size and color, and its optional Bold override still works. Existing saved settings are reused; Next cues previously using the normal default weight will now appear semibold.
- Windows regression checks observe first rendered frames after short/long slide changes, font and layout changes, clock changes and resizing. They also check matching typography across Aptos, Arial, Segoe UI and Verdana, independent cue sizes and the bold override. Screenshots cover those fonts and the in-app preview.
- Documentation reflects current behavior and the operator's confirmation that #20 and #21 are resolved.

No changes were made to Canva exports, refresh scheduling, Presenter tracking, installers or signing.

## Install or upgrade

1. Close CanvaStage.
2. Download `CanvaStage-win-x64.zip` and extract the complete ZIP into a new folder.
3. Run `CanvaStage.Windows.exe` using the same Windows account. Existing preferences, cached content and protected Canva setup are reused. Do not clear cache or disconnect as part of upgrading.

The ZIP includes the Apache-2.0 license and trademark notice. Windows may show an unsigned-app warning.

## Please test

All 59 unit tests pass locally. The Windows release workflow also launches the published application for synthetic runtime and UI verification; physical-display and real-account acceptance remain user checks.

- In Monitor mode, set a large main font size and navigate short → long → short slides. Check both previews and the confidence display for any oversized-text flash or clipping.
- Resize Preview, try all layouts and toggle the clock. Text should fit immediately.
- Try the curated fonts. Current and Next should match in family/default weight while keeping different sizes. Change Next size, color and Bold; current text should not inherit those cue overrides.
- Confirm normal Presenter following and refresh remain working.

Issues #22 and #23 remain open for real-machine confirmation with this release. If either persists, include the selected font, main/Next sizes, layout, Windows scaling and a sanitized diagnostics ZIP. See the [Windows acceptance guide](../windows-acceptance.md).
