# CanvaStage v0.11.3

Operator UI follow-up for [#29](https://github.com/mj00009/CanvaStage/issues/29), [#31](https://github.com/mj00009/CanvaStage/issues/31), [#32](https://github.com/mj00009/CanvaStage/issues/32), [#33](https://github.com/mj00009/CanvaStage/issues/33) and [#34](https://github.com/mj00009/CanvaStage/issues/34).

## Changes

- Live control and Compact preview containers follow the actual output's aspect ratio, showing the whole frame without added side letterboxing, stretching or reflowing output text. Rounded corners remain. Source-size changes and window resizing update the preview container.
- Compact view grows vertically to fit its complete preview. If the screen is too short, the compact content scrolls rather than cropping the preview or hiding controls permanently.
- On top applies only in Compact view. Full view is no longer topmost and has no Always on top control. The saved Compact preference is retained and restored when returning to Compact.
- Adds a little more space below the confidence-preview label, following the latest #29 comment, while keeping the lower gap small.
- Shows Canva connection and Content refresh/local cache as always-visible Settings cards. Removes the expander-inherited larger field/button text.
- Adds aspect-ratio unit tests and Windows checks for actual preview containers at wide, standard and portrait output sizes, compact resizing/topmost transitions, Settings text sizing and the absence of a media player in confidence output.

Presenter tracking, Canva content refresh, text fitting, live-output rendering, saved credentials and cache storage are unchanged. The separate resizable Preview may still letterbox to preserve the complete output frame. Black areas already present in the actual output or slide image are not removed.

## Audio investigation

[#35](https://github.com/mj00009/CanvaStage/issues/35) is not claimed fixed. CanvaStage displays extracted text and static JPEG images; it does not play slide audio/video or control Windows audio routing. Operator guidance now explains checking the presenting app/browser's Windows Volume mixer output device and testing the same slide with CanvaStage closed. No automatic device/browser muting was added because it could silence audience audio. Confirmation of the reported source is still needed.

## Upgrade and test

Close CanvaStage, download `CanvaStage-v0.11.3-win-x64.zip`, extract the entire ZIP into a new folder and run `CanvaStage.Windows.exe` using the same Windows account. Preferences, protected credentials and cached content are reused. The package remains unsigned, self-contained Windows 11 x64, with Apache-2.0 license and trademark notices.

1. Confirm version v0.11.3 in the title/sidebar. Resize Live control and Compact view; the complete preview should keep the output's aspect ratio and rounded corners.
2. Enable On top in Compact, switch to Full view and confirm other apps can cover it. Return to Compact and confirm its saved choice returns.
3. Open Settings & Diagnostics and confirm connection/cache sections are visible without expansion and controls use normal-sized text.
4. Confirm live output and Presenter following remain unchanged on the normal presentation computer and receiver. Leave the linked UI issues open until operator acceptance.
