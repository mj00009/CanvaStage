# CanvaStage v0.11.2

Display identification and selection recovery for [issue #30](https://github.com/mj00009/CanvaStage/issues/30).

## Changes

- Positions numbered identification labels in physical desktop coordinates using the target monitor's DPI. This corrects labels appearing off-screen on scaled displays, including monitors placed to the left of the primary display.
- Automatically refreshes the display dropdown after Windows display changes and before Identify displays or Start output. Refresh preserves the selected monitor instead of losing it during the dropdown rebuild.
- Remembers a disconnected target without silently choosing the primary display. An identifiable reconnect restores the selection but does not restart output; choose Start output when ready. Missing or ambiguous identities require an explicit selection.
- Routes output to the selected current Windows display device and adds logs for selection, resolved target and settled native window bounds. Diagnostic exports include the selected display and current device names, without slide text or credentials.
- Adds regression coverage for scaled identification placement, selection preservation and the actual Setup buttons/dropdown.

The supplied diagnostics showed an initial request for the primary display followed by correctly placed secondary-display requests. They do not prove why the original selection was primary. These changes address the confirmed identification-coordinate bug and strengthen selection handling; real-machine acceptance remains necessary.

Presenter tracking, content refresh, text fitting, cached content and credential storage are unchanged. The wireless-display freeze in #24 remains deferred and is not claimed fixed.

## Upgrade and test

Close CanvaStage, download `CanvaStage-v0.11.2-win-x64.zip`, extract the entire ZIP into a new folder and run `CanvaStage.Windows.exe` using the same Windows account. Saved preferences, protected credentials and cached presentation are reused. The package remains unsigned, self-contained Windows 11 x64, with Apache-2.0 license and trademark notices.

1. Connect the confidence display in Windows Extend mode. Choose Identify displays and confirm both numbered labels appear, including at the laptop's normal scaling.
2. Select the Extended confidence display and choose Start output. Confirm the actual monitor receives the output and Preview still matches it.
3. Stop output, disconnect/reconnect the display and check that the selection is preserved when its identity is available. Output must not restart automatically or switch silently to the primary display.
4. Repeat with the normal presentation computer and receiver before service use. If placement is wrong, export diagnostics and add them to #30, which remains open for acceptance.
