# CanvaStage v0.11.0

This release simplifies setup and makes previews match the confidence output. It remains an unsigned, self-contained Windows 11 x64 portable package.

## Changes

- **Setup** combines loading the Canva deck, choosing the confidence display and previewing/starting output in three numbered steps.
- **Settings & Diagnostics** holds saved Canva connection details, Monitor appearance/layout, advanced refresh/cache preferences and support tools. Credentials are in a collapsed one-time setup section.
- **Compact view** no longer has a Pause Sync button. Return to Full view to resume or manage sync. Manual navigation and existing keyboard shortcuts retain their behavior.
- In-app, compact and separate previews share the actual output visual with uniform scaling. Wrapping, fitted text size, colors, next-line truncation, images and clock match the source output; different aspect ratios may letterbox.
- Opening, resizing or closing Preview no longer moves, starts or stops live output. Before output starts, Preview shows the cached deck using the selected display's viewport, including textless image fallback.
- Restores layout-time text fitting before drawing on the output surface. Keeps existing page/render/display diagnostics and the 40-page drawing regression checks.
- Adds mixed-case text regression tests and automated coverage for settings ownership, compact controls, preview pixel parity, offline navigation/images and narrow-sidebar wrapping.

Saved preferences, protected credentials, authorization and cached content are reused. Presenter tracking, Canva export behavior and refresh scheduling are unchanged.

## Install or upgrade

1. Close CanvaStage.
2. Download `CanvaStage-win-x64.zip` and extract the complete ZIP into a new folder.
3. Run `CanvaStage.Windows.exe` using the same Windows account. Do not disconnect or clear the cache to upgrade.

No separate .NET installation or administrator elevation is required. The ZIP includes the Apache-2.0 license and trademark notice. Windows may show an unsigned-app warning.

## Verification and remaining limitations

All 66 Core tests and the local cross-build pass. The functional source passed [Windows runtime/UI verification](https://github.com/mj00009/CanvaStage/actions/runs/37229598823), including 1:1 preview/output pixel parity, offline previews, first-frame text fitting, 40-page output changes and WPF binding checks. Representative screenshots were reviewed. The release-tag workflow repeats these checks before publishing the package.

The wireless-display freeze reported in [#24](https://github.com/mj00009/CanvaStage/issues/24) remains unresolved and is not claimed fixed. Synthetic rendering cannot verify delivery to a wireless receiver. Investigation is deferred while the operator continues testing. The reported unexpected uppercase text also needs an affected, unedited Canva-exported PPTX; regression tests are not proof that report is resolved.

## Please test

- Follow the Setup steps and confirm saved connection details and appearance settings are available in Settings & Diagnostics.
- Compare live output with the in-app, compact and separate previews at different sizes and aspect ratios. Opening or closing Preview must leave live output unchanged.
- Open Preview before starting output, then navigate cached pages and test Mirror/image fallback.
- Navigate short → long → short slides and at least 40 Presenter pages. Check fitting, next cues, colors, clock and updates on the physical confidence display.
- Confirm Compact view has no Pause Sync button; use Full view to resume after manual navigation.

Test on the actual presentation computer and display before relying on this version during a service. See the [operator guide](../operator-guide.md) and [Windows acceptance guide](../windows-acceptance.md).
