# CanvaStage v0.14.0

This release adds a confirmed Windows audience-mirroring fallback and updates the Presenter status sidebar for [#46](https://github.com/mj00009/CanvaStage/issues/46).

## Changes

- **Setup → Advanced** starts with **Mirror the audience screen**. Choose the audience screen and the separate confidence screen. A Yes/No confirmation names both screens and explains that confidence output will stop. No is the default and leaves output and the Windows layout alone.
- After Yes, Windows mirrors the audience screen onto the confidence screen while keeping the primary operator screen separate. Confirm the result within 15 seconds to keep it. No, closing the dialog or leaving it unanswered restores the previous layout.
- **Restore extended layout** restores the saved arrangement after confirmation. The restore point survives restarting CanvaStage. Confidence output stays stopped until you start it again, and separate output is blocked while the saved fallback remains active.
- The Presenter sidebar shows the current status, a matching outline and a short explanation or recovery step. Pause/Resume and Sync details sit below it. Narrow or short windows keep those controls in the header.

The fallback requires three connected Extended screens and a compatible graphics driver. It cannot reconnect a missing wireless display. CanvaStage does not start or move Canva's audience presentation; keep that presentation on the audience screen.

## Known limitations

[#47](https://github.com/mj00009/CanvaStage/issues/47), unexpected uppercase text in Monitor output, remains under investigation. Diagnosis needs an unedited affected Canva PPTX export. This release does not change text casing or claim to fix the report. The wireless display-loss cause also remains unconfirmed.

## Download and check

Download `CanvaStage-v0.14.0-win-x64.zip`, extract it into a new folder, and run `CanvaStage.Windows.exe` using the normal Windows operator account. Saved credentials, cached content and preferences carry over. The Windows 11 x64 package remains unsigned, portable and self-contained, with `LICENSE` and `TRADEMARKS.md` beside the executable.

Before service use, test the actual three-screen computer: confirm the named pair, primary-screen preservation, both audience images, No and timeout rollback, and restoration after restarting CanvaStage. Some drivers, docks and receivers cannot use the requested clone layout. If a screen disconnects, reconnect it before restoring; use Windows Display settings if the hardware arrangement has changed.

Help and F1 open the [v0.14.0 guide](https://mj00009.github.io/CanvaStage/v0.14.0/). See [mirroring recovery and test scope](../development/display-mirroring.md) and [Windows acceptance](../windows-acceptance.md).
