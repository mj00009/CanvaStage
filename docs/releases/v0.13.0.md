# CanvaStage v0.13.0

This release adds faster Presenter following, optional slide fades and a customizable Mirror clock for [#41](https://github.com/mj00009/CanvaStage/issues/41), [#42](https://github.com/mj00009/CanvaStage/issues/42) and [#45](https://github.com/mj00009/CanvaStage/issues/45).

## Changes

- Healthy accessibility scans now wait 200 ms before scanning again, down from 750 ms. Scans remain sequential, with the same page-count guard, manual pause, cancellation and failure backoff. Canva's accessibility updates and scan time still affect how quickly the display follows.
- In **Settings & Diagnostics → Output clocks and slide changes**, enable **Fade between slides** and choose a duration from 100 to 1000 ms. Fades work in Mirror and Monitor and are off by default. Rapid navigation replaces the fade with the newest page; Blank and Stop take effect immediately.
- **Show current time in Mirror** adds a white clock with a small black shadow at the bottom right. Choose the bottom-left option to move it. Monitor and Mirror have independent size sliders from 16 to 96, with a shared regular or slightly bold weight. Existing preferences keep Mirror's clock off and preserve the Monitor clock setting.
- Long Mirror placeholder text now scales down to fit when a cached slide image is unavailable. Fade capture also checks that the outgoing deck, layout and appearance have rendered, avoiding a stale frame after deck replacement and immediate Presenter resync.

Every preview still copies the same output visual. This release does not establish or fix the wireless display-loss cause reported in [#44](https://github.com/mj00009/CanvaStage/issues/44).

## Download and check

Download `CanvaStage-v0.13.0-win-x64.zip`, extract the whole ZIP into a new folder, and run `CanvaStage.Windows.exe` using the normal Windows operator account. Saved credentials, cached content and preferences carry over. The Windows 11 x64 package remains unsigned, portable and self-contained, and includes the Apache-2.0 `LICENSE` and `TRADEMARKS.md`.

Before service use, compare following speed and CPU use with one Canva Presenter View open. Try both clock positions over light and dark slides. Test fast forward/backward navigation, long and short fades, Blank, Stop and display reconnects on the actual confidence screen. Longer fades take longer to reveal the new slide.

Help and F1 open the published [v0.13.0 guide](https://mj00009.github.io/CanvaStage/v0.13.0/), with reviewed screenshots from the successful tag build. See [output effects](../development/output-effects.md) and [Windows acceptance](../windows-acceptance.md) for test scope.
