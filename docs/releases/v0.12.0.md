# CanvaStage v0.12.0

Simpler Sunday setup and operator fixes for [#36](https://github.com/mj00009/CanvaStage/issues/36), [#37](https://github.com/mj00009/CanvaStage/issues/37), [#38](https://github.com/mj00009/CanvaStage/issues/38), [#39](https://github.com/mj00009/CanvaStage/issues/39) and [#40](https://github.com/mj00009/CanvaStage/issues/40).

## Changes

- Setup defaults to a **Simple** tab. **Start setup** connects Canva, checks the last successfully applied presentation, and starts output on the saved Extended display. **Advanced** retains the numbered deck/display/preview controls for first-time setup or changing choices. Highlighting another deck without Apply does not change the Simple default.
- Reuses unchanged cached content when Canva's modification time matches and the rendered page images are present. Changed, missing or unverifiable content is downloaded first. Shows checking, download, ready and error states, with current-phase byte/page progress where available. Export preparation stays indeterminate rather than inventing a percentage.
- **Restart setup** repeats those checks without forcing an export. Simple **Check slides for updates** avoids downloading unchanged content; it imports reported changes when automatic updates are enabled. Advanced **Check for updates** keeps its existing forced-import behavior for lagging Canva metadata. **Re-download** remains available in Advanced.
- Missing/ambiguous deck choices and unavailable/Primary-only displays produce recovery steps instead of guessing another target. Stopping/cancelling setup start prevents a late download from restarting output; finished content can still be cached.
- **Stop output** destroys the live fullscreen window rather than retaining it hidden. Preview is rebound to a new hidden renderer; Presenter updates and separate Preview cannot resurrect live output. Live control switches its Start button to Stop while output is live. Additional stop/setup-decision logs contain no credentials or slide text.
- Compact scales down without scrollbars, preserving all controls and the entire copied output frame. Short windows reduce preview height first. On top remains Compact-only, and there is still no Pause Sync button. Small previews are reference-only; Full view remains available.
- Full-view scrolling preserves small touchpad wheel deltas and animates movement without overriding scrollbar, keyboard or programmatic navigation.
- Presenter mismatch and other attention states show causes, page counts and actionable recovery instructions. Compact's status tooltip wraps on a dark background. Canva HTTP failures distinguish authorization, access, missing items, throttling and service failures using current Settings controls; failed/cancelled setup resets progress.

Presenter tracking, output text fitting/rendering, automatic content-refresh scheduling, Canva scopes, protected credentials and cache retention remain unchanged. Simple Setup uses the last-applied deck; it does not depend on a starred/default marker in Canva's API. This release does not claim a confirmed Windows casting root cause for the older freeze report or the original physical Stop incident.

## Upgrade and test

Close CanvaStage, download `CanvaStage-v0.12.0-win-x64.zip`, extract the entire ZIP into a new folder, and run `CanvaStage.Windows.exe` under the same Windows account. Saved Canva credentials, cache, appearance and display preferences carry over. The package remains unsigned, self-contained Windows 11 x64 and includes Apache-2.0 `LICENSE` and `TRADEMARKS.md`.

1. Confirm v0.12.0 in the title/sidebar. Use Setup → Simple → Start setup with the unchanged saved deck: it should report synced/ready without another export. Edit Canva content, wait for its modification metadata to update, then repeat and check download progress.
2. Use Advanced to choose a different deck/display and Apply. Confirm Simple uses the last-applied deck and refuses unavailable targets rather than covering the Primary display. Retain Advanced Re-download for edits not yet reflected in Canva's metadata.
3. Test Stop from Live control and Advanced in both modes, with Preview open. The fullscreen window must disappear and remain off through Presenter navigation and Preview reopening; an explicit Start restores it. Cancel a setup start during download and confirm late completion does not start output.
4. Resize Compact smaller with wide and portrait output, check all controls without scrolling, and test gentle/fast touchpad scrolling, scrollbar drag and keyboard navigation in Full view. Compare with normal output on the actual confidence display.
5. Trigger a mismatch or connection failure and confirm the explanation tells you what to check. Keep #36–40 open until operator acceptance on the presentation computer and receiver.
