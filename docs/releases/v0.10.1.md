# CanvaStage v0.10.1

This maintenance release improves Mirror content refresh and preserves authored spaces in Monitor text. It remains an unsigned, self-contained Windows 11 x64 portable package. Issues #20 and #21 remain open pending testing with the reported Canva slides.

## Changes

- [#20 — Stale Mirror content](https://github.com/mj00009/CanvaStage/issues/20): Mirror and textless-page fallback now use a fresh JPEG export instead of Canva's page-preview thumbnails. Visible source page numbers preserve hidden-slide mapping. Reference images use regular export quality, JPEG quality 70, and a width capped at 1280 pixels when dimensions are available, without enlarging smaller designs.
- With automatic content updates enabled, manual **Check for updates** reloads the applied deck even if Canva's reported edit timestamp has not advanced. With automatic updates disabled, it remains a metadata-only check; **Re-download** always forces a reload of the applied deck.
- Older thumbnail-based caches migrate once on an automatic check. A failed new image export, download, or validation retains the complete working deck instead of silently substituting an old thumbnail. Safe logs now record content checks, imports, and deck swaps without slide text, credentials, or signed URLs.
- [#21 — Missing word spaces](https://github.com/mj00009/CanvaStage/issues/21): PowerPoint text runs containing only a space were discarded by the XML parser, merging neighboring words. Imports now preserve authored spaces, including nonbreaking spaces, while keeping words split across runs intact. The reproduced parser fix still needs confirmation against the reported slide.
- Regression coverage includes changed Mirror pixels despite stale thumbnails, lagging edit timestamps, legacy-cache migration, hidden-slide mapping, failed image renders, and whitespace preservation through the Windows import/output path.

## Install or upgrade

1. Close CanvaStage.
2. Download `CanvaStage-win-x64.zip` and extract the complete ZIP into a new folder.
3. Run `CanvaStage.Windows.exe` using the same Windows account as before. Existing preferences, cached content, and protected Canva setup are reused. Do not clear cache or disconnect as part of upgrading.
4. In **Presentation**, choose **Re-download** once before testing the affected slides, so both images and extracted text come from the new import path.

The ZIP includes the Apache-2.0 license and trademark notice. Windows may show an unsigned-app warning. No installer or signing has been added.

## Please test

All 56 unit tests and published Windows synthetic/UI verification passed for the functional fixes. These do not replace real-account and physical-display testing.

- On the slide reported in #21, compare the in-app preview, separate Preview, and confidence output in **Monitor** mode with Canva. Confirm word spaces are correct. Then switch to **Mirror** and compare the slide image separately; report which mode still differs, if either.
- Edit an image-only page in Canva while **Mirror** output is live. Wait for export preparation and download to finish, then confirm the changed graphic appears. If it does not, use **Check for updates** with automatic updates enabled, or **Re-download** regardless of that setting.
- Navigate Presenter, switch modes, and blank/restore output while refreshing. Confirm output remains responsive, retains the current page, and continues following after the deck swap.
- Confirm hidden slides stay excluded and images match their visible pages. A failed refresh should leave the previous deck usable.

Automatic checks still run every 30 seconds and depend on Canva reporting a newer edit timestamp after cache migration. Preparing the PowerPoint and image exports can take several minutes for large decks; updates are not instantaneous. The exact Canva-side cause of the stale-content report is not yet confirmed.

If either issue persists, include the affected mode, the button used, whether refresh completed, and a sanitized diagnostics ZIP from **Setup & diagnostics**. See the full [Windows acceptance guide](../windows-acceptance.md).
