# CanvaStage v0.11.1

Operator polish for issues [#25](https://github.com/mj00009/CanvaStage/issues/25), [#26](https://github.com/mj00009/CanvaStage/issues/26), [#27](https://github.com/mj00009/CanvaStage/issues/27), [#28](https://github.com/mj00009/CanvaStage/issues/28) and [#29](https://github.com/mj00009/CanvaStage/issues/29).

## Changes

- Shows the application version below the sidebar information and in the title bar. The label comes from compiled version metadata, not a hard-coded UI string.
- Includes the version in release ZIP/checksum filenames: `CanvaStage-v0.11.1-win-x64.zip` and `.zip.sha256`. Local builds include the version and build timestamp. Release tags must match the application version.
- Keeps Pause/Resume sync and Sync details beside the main status, removing the Sunday controls duplicates. Mirror/Monitor move from below the preview to Sunday controls, with one pair in each full/compact view.
- Rounds and clips operator preview corners, including Compact view, without changing the shared output visual, its wrapping or the actual confidence display's rectangular frame.
- Reduces Live control preview margins and card padding. Preview actions have more space now that mode controls are in Sunday controls.
- Adds Windows regression checks for displayed version, unique/working mode controls, rounded clipping after resize, tighter margins and sidebar visibility at representative display scales. Existing preview pixel-parity and output navigation checks remain.

Presenter tracking, content refresh, credentials, cached content and confidence-output rendering are unchanged. The wireless-display freeze in #24 remains deferred and is not claimed fixed. The unexpected casing report still needs an affected export.

## Upgrade and test

Close CanvaStage, download the versioned ZIP, extract the entire ZIP into a new folder and run `CanvaStage.Windows.exe` using the same Windows account. Existing preferences, protected credentials and cached presentation are reused. The unsigned package remains self-contained Windows 11 x64 and includes Apache-2.0 license/trademark notices.

Confirm the version is visible, mode controls work in full and compact views, sync controls are only beside the full-view status, and rounded previews remain aligned with the unchanged live output. Repeat on the actual presentation computer and display before service use.

## Verification

Local build/tests and Windows runtime/UI verification must pass before publication. Generated screenshots require visual review; automated checks do not verify delivery to a physical or wireless receiver.
