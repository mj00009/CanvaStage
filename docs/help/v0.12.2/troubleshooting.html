Troubleshooting

Keep the last working content on screen while you investigate. Avoid changing connection settings during a service unless necessary.

Simple Setup needs attention

Check the deck and Extended screen listed on Setup. If either is missing, open Advanced, Apply the intended deck, and select its confidence display. Make sure Apply finishes successfully. Simple Setup will not guess which deck or screen to use.

If authorization has expired, choose Connect Canva and approve access in the browser. You do not need to replace the saved secret just to renew authorization.

Waiting, paused, or presentation mismatch

  1. Open the same deck in Canva Presenter View, with its page counter visible. Keep only one Presenter View open.
  2. Confirm Canva and CanvaStage run at the same Windows permission level; normally neither needs administrator rights.
  3. If following is paused for manual control, return to Full view and choose Resume sync. Using CanvaStage Previous/Next pauses following.
  4. For a mismatch, Apply the correct deck or Re-download it after Canva finishes publishing edits. Hidden slides are excluded; visible totals must match before following starts.
  5. Open Settings & Diagnostics for observation and scan details. If following is unavailable, use manual controls. CanvaStage stays on the last page rather than guessing.

Output missing or on the wrong screen

  1. Check Windows Display settings: the confidence screen must be detected and set to Extend.
  2. In Setup → Advanced, choose Identify displays, select the matching Extended screen, then Start output.
  3. If Windows stops reporting the selected display, CanvaStage stops its output window for safety. Reconnect the screen using Extend. If a restart prompt appears, check the named screen before choosing Yes; No keeps output off. Reconnecting alone never starts output. After a manual Stop, use Start output or Start setup yourself.
  4. If output is black, check whether it is Blanked; choose Restore output.

Focus a full-screen output window and press Escape to close it, or hover at its upper-right corner for the close button. On a single-screen computer, use Preview instead of full-screen output for setup.

The secondary screen freezes or goes blank

Check whether the Presenter page and status, in-app preview, separate Preview, and physical output still change. Record which ones are stuck. Try opening an unrelated window, such as Notepad, on the same secondary screen. If other apps fail there too, check Windows graphics, the cable, dock, or wireless casting as well as CanvaStage. If practical, compare the result with a wired HDMI connection.

The "Confidence display disconnected" warning comes from CanvaStage. It reports that Windows no longer lists the selected screen; it does not establish why the connection dropped. If a cast TV resets, check whether it remains listed in Windows and whether other apps can use it. Include that information with the time of the disconnect when reporting the problem.

Export diagnostics before restarting if you can. Rendering callbacks in the log show that WPF is doing work, but they cannot prove that a TV or wireless receiver displayed the frame. An updating preview does not mean the physical display has recovered.

Download slow, failed, or content still old

  • Canva does not provide a file-size percentage during export preparation. The bar may have no percentage until downloading begins.
  • During the download, CanvaStage can show byte progress if the server supplies the file size. Page-image progress is a separate phase. Neither tells you the total time remaining.
  • Check internet access and retry the action shown in the error. The previous complete deck remains available if a refresh fails.
  • Canva can delay publishing edits. Confirm the edit is saved; Advanced Re-download forces a fresh import of the applied deck.
  • If Mirror reports missing cached images, Re-download before relying on it. Monitor text may still be usable.

Connection or browser return fails

In the Canva integration, check that the authorized redirect matches the URL shown in CanvaStage exactly, including 127.0.0.1, the port, and the trailing slash. Enable both required scopes. If another CanvaStage instance might be using the loopback port, close it and retry Connect Canva.

If a presentation is missing from the list, confirm that the connected Canva account can open it, then choose Test connection and Refresh. Protected credentials belong to the Windows user that saved them. A different Windows account needs its own setup.

Text or image looks different

Monitor chooses the largest main text block and usually leaves out smaller headers and footers. It does not transcribe the whole slide or use OCR. If there is no usable native text, it shows the slide image. If extraction is wrong, share a small PPTX example that reproduces the problem privately, without sensitive content. Do not upload a whole church deck to a public issue without permission.

Fonts and sizes are in Settings & Diagnostics. Current text shrinks to fit, while the Next cue stays on one line. Mirror images are for reference, not audience projection. Preview copies the output layout, but a very small preview cannot show whether people on stage can read it.

The confidence TV plays audio

CanvaStage does not play slide media or change audio routing. Test while CanvaStage is closed and check Windows Volume mixer for the Canva app or browser's output device. Do not mute the audience audio path during a service.

Report a problem safely

  1. Record the app version, time, action, and what you expected. Note connection type (HDMI, dock, wireless casting) for display problems.
  2. Choose Settings & Diagnostics → Export diagnostics. CanvaStage creates a ZIP on the desktop.
  3. Review the bundle before sharing. It excludes credentials, tokens, codes, slide text, and slide images, but system paths or device identifiers can still be sensitive. GitHub issues in this repository are public. Do not attach secrets, real presentation screenshots, or sensitive logs there.
  4. Open a GitHub issue with a description that contains no private information. If the maintainer needs sensitive diagnostics, arrange to share them privately.

The local log is %LOCALAPPDATA%\CanvaStage\canvastage.log. New log timestamps are UTC with a Z; app clocks are local time. Older entries may use an explicit offset.

Help does not open

The website needs internet access. If CanvaStage cannot launch your browser, it shows the help address in a dialog so you can copy it. If the browser opens but the page does not load, check the connection in the browser.
