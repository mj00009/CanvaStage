Get CanvaStage

  1. Open the v0.12.0 release and download CanvaStage-v0.12.0-win-x64.zip under Assets. Do not choose “Source code.”
  2. Right-click the ZIP and choose Extract All. Keep the extracted files together.
  3. Open CanvaStage.Windows.exe from the extracted folder. No .NET installation or administrator rights are needed.
The app is unsigned. Windows may warn before launching it. Only proceed if you downloaded the intended package from this repository and trust it. If your organization blocks unsigned apps, ask your administrator; do not disable Windows security.

What you need

  • Windows 11 x64, with Canva and CanvaStage running under the normal operator account.
  • A primary operator screen and a second screen configured to Extend. With one screen, use Preview for testing.
  • A configured Canva connection for this Windows user. Ask the person responsible for first-time setup if it is not already saved.

Downloaded content remains available after closing the app. Internet access is needed to authorize Canva, check or download changes, and open this help site.

Two output modes

Monitor displays the largest main text block, omitting smaller headers and footers where possible. Long text shrinks to fit. Mirror displays a reference image of the slide; it does not play embedded audio or video.

CanvaStage follows the page counter exposed by Canva Presenter View through Windows accessibility. It does not capture your screen or inspect browser traffic. Manual page controls remain available.
