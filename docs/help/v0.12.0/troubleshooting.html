Troubleshooting

Keep the last working content on screen while you investigate. Avoid changing connection settings during a service unless necessary.

Simple Setup needs attention

Confirm the deck and Extended screen listed on Setup. If either is missing, open Advanced, successfully Apply the intended deck, and select its confidence display. Simple Setup will not guess a deck or start output on an arbitrary screen.

If authorization is expired, choose Connect Canva and approve it in the browser. Do not replace the saved secret simply because authorization needs renewing.

Waiting, paused, or presentation mismatch

  1. Open the same deck in Canva Presenter View, with its page counter visible. Keep only one Presenter View open.
  2. Confirm Canva and CanvaStage run at the same Windows permission level; normally neither needs administrator rights.
  3. If the status is Paused — manual control, return to Full view and choose Resume sync. Using CanvaStage Previous/Next pauses following intentionally.
  4. For a mismatch, Apply the correct deck or Re-download it after Canva finishes publishing edits. Hidden slides are excluded; visible totals must match before following starts.
  5. Open Settings & Diagnostics for observation and scan details. If following is unavailable, use manual controls; the last page is held instead of guessing.

Output missing or on the wrong screen

  1. Check Windows Display settings: the confidence screen must be detected and set to Extend.
  2. In Setup → Advanced, choose Identify displays, select the matching Extended screen, then Start output.
  3. After a disconnect/reconnect, start output explicitly. Reconnection does not restart a live session automatically.
  4. If output is black, check whether it is Blanked; choose Restore output.

Focus a full-screen output window and press Escape to close it, or hover at its upper-right corner for the close button. On a single-screen computer, use Preview instead of full-screen output for setup.

The secondary screen freezes or goes blank

Compare the Presenter page/status, in-app preview, separate Preview, and physical output. Record which still change. Try an unrelated window, such as Notepad, on the same secondary screen. If other apps also fail there, investigate Windows graphics, the cable, dock, or wireless casting as well as CanvaStage. When practical, compare with wired HDMI.

Export diagnostics before restarting if possible. Rendering callbacks in the log show WPF activity; they cannot prove a TV or wireless receiver actually displayed the frame. Do not assume a freeze is fixed just because the preview updates.

Download slow, failed, or content still old

  • Export preparation has no known file-size percentage. The bar may be indeterminate before downloading begins.
  • During transfer, byte progress is available if the server supplies a length. Image-page progress is a separate phase; neither is an estimate of total time remaining.
  • Check internet access and retry the action shown in the error. The previous complete deck remains available if a refresh fails.
  • Canva can delay publishing edits. Confirm the edit is saved; Advanced Re-download forces a fresh import of the applied deck.
  • If Mirror reports missing cached images, Re-download before relying on it. Monitor text may still be usable.

Connection or browser return fails

In the Canva integration, compare the authorized redirect to the exact URL shown in CanvaStage, including 127.0.0.1, port, and trailing slash. Ensure both required scopes are enabled. Close another CanvaStage instance that might occupy the loopback port, then retry Connect Canva.

If a presentation is not listed, confirm the connected Canva account can open it, then Test connection and Refresh. Protected credentials belong to the Windows user that saved them; a different Windows account needs its own setup.

Text or image looks different

Monitor chooses one largest main text block; it is not a full-slide transcription or OCR. Smaller headers/footers are usually excluded. Without usable native text, the slide image is used. Share a minimal non-sensitive PPTX reproducer privately if extraction is wrong; never upload a whole church deck to a public issue without permission.

Fonts and sizes are in Settings & Diagnostics. Current text auto-shrinks; the Next cue intentionally stays one line. Mirror is reference quality, not audience projection quality. Preview copies output layout, but very small previews cannot demonstrate readability from the stage.

The confidence TV plays audio

CanvaStage does not play slide media or change audio routing. Test while CanvaStage is closed and check Windows Volume mixer for the Canva app or browser's output device. Do not mute the audience audio path during a service.

Report a problem safely

  1. Record the app version, time, action, and what you expected. Note connection type (HDMI, dock, wireless casting) for display problems.
  2. Choose Settings & Diagnostics → Export diagnostics. A ZIP is created on the desktop.
  3. Review the bundle before sharing. It excludes credentials, tokens, codes, slide text, and slide images, but system paths or device identifiers can still be sensitive. GitHub issues in this repository are public. Do not attach secrets, real presentation screenshots, or sensitive logs there.
  4. Open a GitHub issue with a non-sensitive description. Arrange private sharing of sensitive diagnostics with the maintainer if needed.

The local log is %LOCALAPPDATA%\CanvaStage\canvastage.log. New log timestamps are UTC with a Z; app clocks are local time. Older entries may use an explicit offset.
