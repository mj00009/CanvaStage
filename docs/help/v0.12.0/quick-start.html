Sunday quick start

For a computer that already has its Canva connection, presentation, and confidence display saved.

First time on this computer? Use first-time setup before following these steps.

1. Start with saved choices

  1. Connect the confidence screen. In Windows Display settings, confirm it is an Extended display, not a duplicate of the operator screen.
  2. Open CanvaStage using the same Windows account used during setup.
  3. Open Setup → Simple. Check the named presentation and confidence display, then choose Start setup.
  4. Wait for the message saying the presentation is synced and ready and confidence output is live. If browser authorization opens, approve access using the intended Canva account and return to CanvaStage.

An unchanged presentation with a complete, verified cache is reused without downloading again. Changed or incomplete content downloads first. Large exports can take several minutes; the progress bar describes the current phase, not the total time remaining.

2. Confirm following

  1. Open the same presentation in Canva and start Presenter View, with its page counter visible.
  2. Keep only one Presenter View open. CanvaStage and Canva should both run normally, not one as administrator and the other normally.
  3. Confirm CanvaStage says Following Canva. Move forward and back in Presenter View and verify the confidence screen follows.

Hidden slides are excluded from confidence numbering. If visible-page totals do not match, CanvaStage holds the last page instead of guessing. Use sync troubleshooting.

3. Use the simple controls

  • Monitor: readable text for songs, readings, and speaking.
  • Mirror: the original slide image for sermon graphics and other visual references.
  • Compact view: the output preview with Mirror/Monitor, Blank/Restore, On top, and Full view. Resize it as needed.
  • Blank output: temporarily make the confidence screen black without stopping following. Choose Restore output to bring it back.

Compact view intentionally has no Pause Sync button. Use Full view if you need to manage following. Manual Previous/Next in CanvaStage pauses following; choose Resume sync to return to the Canva Presenter page.

4. Check the physical screen

The in-app preview and Open Preview copy the actual confidence-output layout instead of wrapping text separately. A resized Preview may show empty borders. Check the real monitor before the service: the preview cannot prove that a cable or wireless display is receiving frames.

5. Finish safely

Return to Full view and choose Stop output, then close CanvaStage. Closing the app stops its windows but retains the deck, connection, and preferences. Do not use Disconnect or Clear cache as part of normal shutdown.

If a full-screen confidence window blocks your screen, focus it and press Escape, or hover over its upper-right corner to reveal the close button.
