First-time & advanced setup

For the person maintaining the presentation computer. Most of these settings only need to be changed once.

Configure the Canva connection

Important deployment limitation: Canva's official security recommendations do not support desktop REST API integrations that store client credentials. CanvaStage uses locally protected credentials for a self-managed computer; Windows protection does not make this a Canva-supported integration. Publishing this application's source does not authorize broader distribution of a Canva integration or sharing its credentials.

You need access to the intended Canva account, multi-factor authentication, and permission to configure an integration. Use the Windows account that will operate CanvaStage.

  1. In CanvaStage, open Settings & Diagnostics → Canva connection. Choose Copy redirect URL.
  2. Open the Canva Developer Portal, sign in, and open Your integrations. Create an integration appropriate for your account and intended use.
  3. On the integration's configuration page, copy its Client ID. Generate and save its Client Secret privately; Canva does not show the secret again.
  4. Under Scopes, enable only design:meta:read and design:content:read.
  5. Under Authentication → Authorized redirects, add the exact URL copied from CanvaStage. The current value is http://127.0.0.1:27843/callback/, including its trailing slash. Use the app's value if it differs. Do not substitute localhost.
  6. Return to CanvaStage, enter the Client ID and Client Secret, and choose Save configuration.
  7. Choose Connect Canva, authorize the intended account in the browser, then return to the app.

A Public integration can be used in draft state for individual testing; broader availability requires Canva's review. Private integrations require Canva Enterprise. A development loopback redirect cannot remain when submitting a Public integration for review. Consult Canva's integration guidance and terms for your deployment.

The secret and tokens are protected for the current Windows user and reused after closing the app. Another Windows account must configure its own connection. Replace saved secret is for an intentional credential change. Disconnect removes the local protected connection; it is not a shutdown button.

Load the presentation

  1. Open Setup → Advanced → 1. Load the Canva deck.
  2. Choose Refresh to list presentations accessible to the connected account.
  3. Select the intended deck and choose Apply. Wait for the import to finish.

Simple Setup remembers the last successfully applied presentation. Highlighting another item without applying it does not change that default. Large exports take time; export preparation has no known percentage. Byte progress appears when the download's size is available, followed by page-image progress.

Choose the confidence display

  1. In Windows, open Settings → System → Display and set the screens to Extend.
  2. In Setup → Advanced → 2. Choose the confidence display, choose Identify displays.
  3. Match the temporary on-screen number to the dropdown's name, resolution, and Primary/Extended label. Choose the stage's Extended display.
  4. Choose Open Preview to inspect content, then Start output to verify placement on the physical screen.

Simple Setup refuses a missing, ambiguous, or Primary remembered display. Advanced allows explicit selection; with only one display, Preview is safest. Disconnecting the selected display stops output rather than moving it onto the operator screen. Reconnecting may restore its selection, but you must explicitly start output again.

Adjust Monitor appearance

In Settings & Diagnostics, choose the Monitor font, maximum size, colors, layout, next-line behavior, and optional clock. Changes apply immediately to output and previews and are saved locally.

  • The main text shrinks when necessary; the selected font size is a maximum.
  • The Next cue shares the selected font family, with its own size, color, and optional Bold setting. Long cues use an ellipsis rather than multiple display lines.
  • Use contrast guidance and test from the stage. Mirror images are static, reference-quality JPEGs; no embedded media plays.

Content updates during a service

Automatically apply Canva content updates checks the applied deck after each check completes, normally about every 30 seconds. Failures back off. A complete new download is applied without requiring you to stop and restart Presenter View or output. Until it succeeds, the working cached deck stays active.

Canva may publish edits or its modification timestamp with a delay. With automatic updates enabled, Advanced Check for updates explicitly imports fresh content. With automatic updates disabled, it checks metadata and reports changes without applying them. Simple Check slides for updates avoids an unchanged download. Re-download always imports the applied deck, regardless of a different highlighted dropdown item.

For a predictable service, finalize edits beforehand, check the preview, and disable automatic application if you do not want content changed mid-service. Presenter page following is separate from content refresh; disabling updates does not pause following.

Cache and housekeeping

  • Clean old downloads removes obsolete download generations but keeps the current presentation.
  • Clear cache removes downloaded presentation content and returns to the demo. It retains connection credentials, preferences, and the saved presentation selection; content must be downloaded again.
  • Normal app closing keeps the presentation and protected connection. Updating the extracted application files does not intentionally erase this per-user data.
