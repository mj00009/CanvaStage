CanvaStage help

CanvaStage shows a readable confidence display for speakers and musicians. It follows the current page in Canva Presenter View.

Running a service?

Use the saved presentation and display. Check that they're ready, start Presenter View, then use Compact view during the service.

Setting up a computer?

Configure the Canva connection once, load the right deck, and choose the Extended confidence display.

Get CanvaStage

  1. Open the v0.14.1 release and download CanvaStage-v0.14.1-win-x64.zip under Assets. Do not choose "Source code."
  2. Right-click the ZIP and choose Extract All. Keep the extracted files together.
  3. Open CanvaStage.Windows.exe from the extracted folder. You do not need to install .NET or run the app as administrator.
The app is unsigned. Windows may warn before opening it. Only continue if you downloaded the intended package from this repository and trust it. If your organization blocks unsigned apps, ask your administrator. Do not disable Windows security.

What you need

  • Windows 11 x64, with Canva and CanvaStage running under the normal operator account.
  • A primary operator screen and a second screen configured to Extend. With one screen, use Preview for testing.
  • A configured Canva connection for this Windows user. Ask the person responsible for first-time setup if it is not already saved.

The downloaded presentation stays on the computer when you close the app. You need internet access to authorize Canva, check or download changes, and open this help site.

Two output modes

Monitor shows the largest main text block and leaves out smaller headers and footers where possible. Long text shrinks to fit. Mirror shows a reference image of the slide. It does not play embedded audio or video.

CanvaStage follows the page counter exposed by Canva Presenter View through Windows accessibility. It does not capture your screen or inspect browser traffic. Manual page controls remain available.

v0.14.1 adds an optional Match slide capitalization setting for uppercase text introduced by Canva's PowerPoint export. It starts off and keeps original text when matching is uncertain. The audience-mirroring fallback, Presenter sidebar and optional clocks and slide fades remain available.
