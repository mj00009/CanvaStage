First-time & advanced setup

Set up the presentation computer here. Most settings only need to be changed once.

Configure the Canva connection

Canva does not support this desktop integration. Its official security recommendations rule out desktop REST API integrations that store client credentials. CanvaStage protects credentials locally on a computer you manage, but Windows protection does not make the integration Canva-supported. Publishing the source code does not authorize wider distribution of a Canva integration or sharing its credentials.

You need access to the intended Canva account, multi-factor authentication, and permission to configure an integration. Use the Windows account that will operate CanvaStage.

  1. In CanvaStage, open Settings & Diagnostics → Canva connection. Choose Copy redirect URL.
  2. Open Your apps in the Canva Developer Portal. Choose Create an app and an audience appropriate for your account and use, following Canva's developer terms.
  3. Open Outside Canva and choose Start integrating. On Configuration, confirm Canva REST APIs is enabled under Integration methods.
  4. Under Credentials, copy the Client ID. Generate and save the Client Secret privately; Canva does not show the secret again.
  5. In the REST API Scopes, enable only Read for design:meta and design:content (design:meta:read and design:content:read). CanvaStage does not need Write permissions.
  6. Open Outside Canva → Redirect URLs and enter the exact URL copied from CanvaStage in a redirect field such as URL 1. The current value is http://127.0.0.1:27843/callback/, including its trailing slash. Use the app's value if it differs. Do not substitute localhost. Return navigation is not needed for CanvaStage.
  7. Return to CanvaStage, enter the Client ID and Client Secret, and choose Save configuration.
  8. Choose Connect Canva, authorize the intended account in the browser, then return to the app.

Existing integrations may still show Your integrations → Configure your integration, with separate Scopes and Authentication/Authorized redirects sections. Enter the same credentials, Read scopes, and exact redirect in those fields. If the saved connection works, you do not need to recreate it because the portal labels changed.

Private apps require Canva Enterprise, and public distribution requires Canva's review. Loopback redirects are for local development and testing and must be removed afterward. This guide describes CanvaStage's local setup, not an approved public integration. Follow Canva's current REST API quickstart, review requirements, and security guidance for your deployment. Use CanvaStage's two Read scopes and the URL above, rather than the starter kit's broader permissions or example redirect.

Show the connection settings

CanvaStage protects the secret and tokens for the current Windows user and reuses them after you close the app. Another Windows account needs its own connection. Use Replace saved secret when changing credentials. Disconnect removes the local protected connection; do not use it to shut down the app.

Load the presentation

  1. Open Setup → Advanced → 1. Load the Canva deck.
  2. Choose Refresh to list presentations accessible to the connected account.
  3. Select the intended deck and choose Apply. Wait for the import to finish.

Simple Setup remembers the last presentation you successfully applied. Selecting another item without choosing Apply does not change the default. Large exports take time, and Canva does not provide a percentage during export preparation. Once downloading starts, CanvaStage shows byte progress if it knows the file size, then progress for the page images.

Choose the confidence display

  1. In Windows, open Settings → System → Display and set the screens to Extend.
  2. In Setup → Advanced → 2. Choose the confidence display, choose Identify displays.
  3. Match the temporary on-screen number to the dropdown's name, resolution, and Primary/Extended label. Choose the stage's Extended display.
  4. Choose Open Preview to inspect content, then Start output to verify placement on the physical screen.

Simple Setup will not start output if the saved display is missing, could refer to more than one screen, or is Primary. Use Advanced to choose a display yourself. With only one screen, Preview is safest. If the selected display disconnects, CanvaStage stops output instead of moving it onto the operator screen. Reconnecting may restore the selection, but you still need to start output again.

Adjust Monitor appearance

In Settings & Diagnostics, choose the Monitor font, maximum size, colors, layout, next-line behavior, and optional clock. CanvaStage saves these settings locally and applies changes immediately to output and previews.

  • The selected font size is a maximum. Main text shrinks when needed to fit.
  • The Next cue shares the selected font family, with its own size, color, and optional Bold setting. Long cues use an ellipsis rather than multiple display lines.
  • Use the contrast guidance, then check readability from the stage. Mirror uses static JPEGs for reference and does not play embedded media.

Content updates during a service

With Automatically apply Canva content updates enabled, CanvaStage checks the applied deck about every 30 seconds after the previous check finishes. It waits longer between checks after failures. When a new download is complete, it applies the content without stopping Presenter View or output. The working cached deck stays active until the download succeeds.

Canva can take time to publish an edit or update its modification timestamp. In Advanced, Check for updates imports fresh content when automatic updates are enabled. When they are disabled, it checks metadata and reports changes without applying them. In Simple Setup, Check slides for updates skips the download if nothing has changed. Re-download always imports the applied deck, even if a different item is selected in the dropdown.

Finish edits before the service and check the preview. If you do not want content to change during the service, disable automatic application. Presenter following and content refresh are separate, so disabling updates does not pause following.

Cache and housekeeping

  • Use Clean old downloads to remove older downloads while keeping the current presentation.
  • Clear cache removes downloaded presentation content and returns to the demo. It keeps connection credentials, preferences, and the saved presentation selection, but you will need to download the content again.
  • Closing the app normally keeps the presentation and protected connection. Updating the extracted application files is not intended to erase this Windows user's saved data.
