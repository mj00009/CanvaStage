Sunday quick start

Use these steps if the computer already has a saved Canva connection, presentation, and confidence display.

First time on this computer? Use first-time setup before following these steps.

1. Start with saved choices

  1. Connect the confidence screen. In Windows Display settings, confirm it is an Extended display, not a duplicate of the operator screen.
  2. Open CanvaStage using the same Windows account used during setup.
  3. Open Setup → Simple. Check the named presentation and confidence display, then choose Start setup.
  4. Wait until CanvaStage says the presentation is synced and ready, and confidence output is live. If an authorization page opens in the browser, approve access using the intended Canva account, then return to CanvaStage.

CanvaStage reuses an unchanged presentation if it can verify that the saved download is complete. If the content has changed or the download is incomplete, it downloads the presentation before starting output. Large exports can take several minutes. The progress bar shows the current phase, not the total time remaining.

2. Confirm following

  1. Open the same presentation in Canva and start Presenter View, with its page counter visible.
  2. Keep only one Presenter View open. Run CanvaStage and Canva at the same Windows permission level. Normally, neither needs administrator rights.
  3. Confirm CanvaStage says Following Canva. Move forward and back in Presenter View and verify the confidence screen follows.

CanvaStage excludes hidden slides from its page numbering. If its visible-page total does not match Presenter View, it stays on the last page instead of guessing. See sync troubleshooting.

3. Use the simple controls

  • Choose Monitor for readable text during songs, readings, and speaking.
  • Use Mirror for the original slide image, such as sermon graphics or other visual references.
  • Switch to Compact view for the output preview and Mirror/Monitor, Blank/Restore, On top, and Full view controls. Resize it as needed.
  • Choose Blank output to make the confidence screen black while following continues. Restore output brings the content back.

Compact view has no Pause Sync button. Use Full view to manage following. Previous/Next in CanvaStage pauses following; choose Resume sync to return to the current Canva Presenter page.

4. Check the physical screen

The in-app preview and Open Preview copy the confidence display's layout, so text wraps the same way. Resizing Preview may leave empty borders. Before the service, check the physical monitor too. The preview cannot tell you whether a cable or wireless display is receiving the image.

5. Finish safely

Return to Full view, choose Stop output, then close CanvaStage. Closing the app closes its windows and keeps the deck, connection, and preferences. You do not need Disconnect or Clear cache for normal shutdown.

If a full-screen confidence window blocks your screen, focus it and press Escape, or hover over its upper-right corner to reveal the close button.
